## [v0.2.0] - 2026-06-07

### Highlights

- Configuration file support (`.api-style.yaml`) for project-level settings
- Multi-file linting with glob patterns and recursive directory search
- Watch mode for continuous linting during development
- Git pre-commit hook generator for blocking commits with violations

### Added

- **Configuration file support** - Load settings from `.api-style.yaml` with profile, level, include/exclude patterns, exceptions, and severity overrides
- **Multi-file linting** - Lint multiple files with glob patterns (`api/*.yaml`) and `--recursive` flag
- **Watch mode** - `--watch` flag for continuous re-linting on file changes
- **Pre-commit hook** - `api-style hooks init` command to install git pre-commit hooks
- **New CLI flags** - `--config`, `--recursive`, `--watch` for lint command
- **MultiLintReport type** - Aggregate results from linting multiple files
- **Automated API Governance guide** - Documentation for AI-first API design workflow

### Changed

- `api-style lint` now accepts multiple file arguments
- CLI flags override config file settings

### Dependencies

- Added `github.com/fsnotify/fsnotify v1.10.1` for watch mode

## [v0.1.0] - 2026-06-06

See [v0.1.0 Release Notes](v0.1.0.md) for full details.

### Highlights

- OpenAPI style linting with vacuum integration and configurable style profiles (Azure, Google, custom)
- LLM-powered API evaluation using Claude for semantic analysis beyond static rules
- MCP server for Claude Desktop and Claude Code integration with resources and prompts
- Web UI with Lit components and REST API backend for browser-based linting

### Added

- Core types package with `LintReport`, `Violation`, `StyleProfile`, and `EvaluationResult` structs
- Vacuum-based linting engine with severity mapping and JSON path extraction
- Style profile loading from YAML/JSON with built-in Azure and Google profiles
- LLM evaluation with Claude using structured prompts and JSON output
- Analysis orchestrator combining static linting and LLM evaluation
- CLI with `lint`, `analyze`, and `evaluate` commands
- Multiple output formats: text, JSON, SARIF
- MCP server with `openapi://` resource URIs for spec access
- Claude Code hooks for pre-commit and post-save linting
- SARIF 2.1.0 output format for IDE integration
- REST API server with `/api/lint` and `/api/profiles` endpoints
- Web UI with Lit components: spec editor, profile selector, results panel
